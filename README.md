### 🛡️ Network Intrusion Detection System (NIDS)
**[View Repository →](https://github.com/forbidden402/Network-Intrusion-Detection-System)**

A real-time Network Intrusion Detection System with Deep Packet Inspection, built for local network security monitoring and forensic analysis.

- Live telemetry dashboard with protocol distribution & threat frequency charts
- Deep Packet Inspection for DNS, HTTP, and ICMP payloads
- Entity investigation profiles with OSINT-based threat intelligence (geolocation, ISP, abuse score)
